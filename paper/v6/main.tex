\title{PyEXPINT: A Validated Backend-Independent Framework for Exponential General Linear Integrators}

\author{Francisco R. Villatoro}
\orcid{0000-0003-4314-6213}
\affiliation{%

\email{frvillatoro@uma.es}  % correspondence address recorded in the project history

\begin{abstract}
Exponential integrators treat a dominant linear operator exactly and the remaining nonlinear dynamics explicitly, but a usable implementation must also fix how method coefficients, matrix-function actions, history, adaptivity and diagnostics interact. \pkg{} is a Python framework that expresses exponential Runge--Kutta, multistep and general linear schemes in a single explicit exponential general linear form and executes the same method definitions through interchangeable realizations of the action of phi-functions. The release reconstructs the 47-entry catalogue of the EXPINT package. The archived cross-check of two specified problems reports near-roundoff agreement with the original 2005 implementation for 42 entries, agreement after a one-line correction for four further entries, and regenerated output coefficients for the remaining entry. The framework provides an operator-expression layer for combinations of phi-functions, dense, diagonal, full-Arnoldi, KIOPS-type, real-Leja and hybrid realizations, a rule-based selector, algebraic fusion of compatible actions, fixed-step integration with explicit startup policies, step-doubling control and the embedded ETD34 pair, whose error estimate is shown to vanish for state-independent forcing. Work-precision experiments show that method rankings depend on the work observable, and paired timing campaigns show that backend conclusions are configuration and hardware dependent, so algorithmic work and achieved accuracy are reported as primary evidence. The manuscript package preserves comparison records and data-to-figure and data-to-table transformations; the software candidate and its execution-level validation are identified separately.
\end{abstract}
